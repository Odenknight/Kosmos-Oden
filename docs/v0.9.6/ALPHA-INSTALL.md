# Install Kosmos-Oden 0.9.6

1. Use Obsidian 1.13.0 or newer. Close it and extract the release ZIP.
2. Copy the files inside the extracted `kosmos-oden/` folder into `<vault>/.obsidian/plugins/kosmos-oden/`. When upgrading, keep the existing `data.json`.
3. Reopen Obsidian and enable Kosmos-Oden in **Settings → Community plugins**.
4. Open **Settings → Kosmos-Oden → E-Z setup**. Ask a question using words you remember from a Markdown note, then open a result to read the source. The open-book ribbon icon returns you to the Librarian.

The local Librarian needs no account, model download or connection to an assistant. In its tab, expand the help questions for MCP, optional GKX tags and sync. [Release downloads and checksums](https://github.com/Odenknight/Kosmos-Oden/releases/tag/0.9.6)

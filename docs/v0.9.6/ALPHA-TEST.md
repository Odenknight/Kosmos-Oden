# Check the 0.9.6 Librarian in Obsidian

In a disposable vault, create a Markdown note at the root and a second one in a private folder. Put a distinctive phrase in each.

1. With external sharing off, click **E-Z setup** in Kosmos-Oden settings. Wait for the note count, disconnect from the network, and search for each phrase. Open a result and check its passage against the note.
2. Ask “Which sync services can I use?” and expand the MCP and tagging questions. The help is bundled with the plugin.
3. Edit a phrase, rename the note, then delete that test note. Repeat the search after each change to check the returned passage and path.
4. Reload the plugin and reopen the Librarian from the command palette. Check that the remaining note is searchable and your folder-sharing choices are preserved.

The automated desktop trial runs these search and lifecycle checks with a temporary vault and an installed release ZIP. [Obsidian smoke script](https://github.com/Odenknight/Kosmos-Oden/blob/0.9.6/scripts/obsidian-smoke.mjs)

4. Reject retired namespace identifiers in product-facing copy, code, paths, commands, and APIs.
5. Run each product's full verification suite and inspect built artifacts for stale branding and behavioral drift.

Return a per-product change list, tests and results, and remaining blockers. Do not broaden write authority as part of branding work.

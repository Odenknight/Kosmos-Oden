Kosmos remains version 0.8.3 and now consumes Engine 2.2.0 development source
`777ba170b905952817e364f125c794152f118fa4`. Package declaration, Git lock resolution,
script allowance, lock guard and adapter fixture agree on that immutable commit.

serialization/scanning improvements and private managed Graphiti hardening.

## Verification

On September 13, 2026, `npm run verify` passed all 422 unit tests plus type,
build, version, lock, artifact, invariant and renderer-provenance checks. The
first run found the old exact-pin assertion; updating it to the selected commit
restored the intended immutable dependency check.

The browser commands with `--workers=2` passed 40 desktop/mobile Chromium cases
and 38 Firefox/WebKit cases. The initial default-worker Chromium run passed 38
and timed out on two local-engine graph downloads. Both cases passed with one
worker, then all 78 matrix cases passed with two workers and unchanged deadlines.
This records a concurrency-sensitive test limitation; it does not establish
unrestricted parallel browser performance or independent hardware-GPU evidence.

## Native and release limits

The installed plugin reports a concurrent Notes workspace build, `efcbcb4`,
from PR80. It was preserved rather than replaced by this dependency-only branch.
The combined Notes/Engine artifact still requires native acceptance. Earlier
native receipts must not be attributed to this new dependency.

This is a development integration. Engine's two-second watcher target remains
unmet, the full 24-hour soak is open, and this pin does not establish Graphiti
promotion, released Engine compatibility or GKOS conformance. To roll back the
development pin, restore the prior package/lock/guard/fixture coordinates
together, rebuild and rerun consumer verification; do not float to a branch.

## Frozen decisions

- Logical read/build/request deadlines: 10/20/25 seconds; socket idle backstop remains 30 seconds. Use monotonic checks before/after awaits, after synchronous indexing and before publication. Test-specific limits are injectable, not user-facing settings.
- Physical text reads for Kosmos provider and viewer share capacity 16, with zero pending queue. This bound does not cover Obsidian's own indexer, other plugins, or separate sync/migration workflows. A versioned host-realm registry is keyed by the stable Vault object. Verify object continuity during plugin reload; a new plugin instance cannot discard outstanding entries.
- An unresolved path cannot be read again until settlement. Logical timeout does not release its permit, reuse its value as current content, or cancel sibling I/O. Capacity exhaustion returns unavailable. Settlement releases its own entry; a real host-process restart is the last-resort recovery for an indefinitely blocked host API. No automatic restart is introduced.
- Preserve single-flight logical builds and build deadlines. Edits/policy changes require a fresh attempt within the original deadline. Stage source-file changes and index into a new candidate; check generation/deadline before atomically replacing published state and consuming dirty events. Incremental I/O remains incremental, though candidate indexing reparses retained source files; benchmark this correctness tradeoff before package qualification.
- Server finalization owns logical admission, once per request in its captured epoch. Disconnect, abort, deadline and stop settle the request lifecycle without releasing physical permits. A guarded response suppresses late raw writes; an active-operation guard suppresses late tool calls and traversal. Stop cannot let old completions decrement new counters.
- REST: typed timeout 504, provider unavailable 503, real absence retains existing not-found behavior. MCP tool failures: structured `isError: true` with application reason. Whole-request deadline: HTTP 504 with JSON-RPC application error `-33001`, captured request ID when available, and `data.reason: timeout`; this code is outside the JSON-RPC reserved range. Do not advertise automatic retry while physical capacity may remain exhausted. Preserve validation-first protocol errors.
- Viewer snapshots/deltas stage hashes and pending events until successful current-generation publication. Close/reopen, errors and deadline cannot publish late state. Failures retain pending work and show the existing disconnected status; a single 1.5-second deferred retry timer recovers a visible view when physical work settles. Hidden views wait for visibility; close cancels the timer. Retry attempts do not enqueue physical reads or exceed the shared bound.

Changes to these choices require a new freeze revision and affected tests. No behavioral merge or deployment is approved merely by this planning receipt. Existing historical seam reservations were notified through Codex mailbox seq30; monitor for conflicting work before integration.

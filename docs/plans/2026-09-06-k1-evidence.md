## Implemented

Service base URL validation rejects user information, non-root paths, query strings and fragments before connect, health or event requests. Valid loopback roots remain accepted. SSE 401 and 403 terminate automatic retries with a generic reconnect instruction. Transient retry and 409 reset behavior remain separate.

Three additional tests verify zero network requests for invalid origins and no retry timer after each authorization denial. Only synthetic credentials are used. Existing renderer, offline folder, Obsidian API and sync behavior are retained.

## Validation

Windows, Node 24.18.0. npm run verify passed all 320 tests, with zero failures or skips, plus typecheck, production build, versions, lock integrity, artifact, invariant and renderer provenance checks.

The initial sandboxed build could not resolve workspace paths due to filesystem access. The authorized unsandboxed verification completed successfully; this was an environment failure, not a passing test run.

Browser: npm run test:browser:chromium ran 36 Chromium/mobile cases with eight workers: 30 passed and six failed. npx playwright test --last-failed --workers=1 then passed all six in 9.8 seconds. This is consistent with load contention but does not erase the initial failures or prove their root cause. No source changed between runs.

This slice does not claim Node 22/26, real Engine revocation, real Obsidian, native supervisor or packaged platform qualification. No new service artifact was produced. Engine dependency remains unchanged until K2. Hosted workflow results for this implementation must be checked after push; local evidence does not imply hosted success.

## Compatibility and rollback

Service addresses must be origins rather than resource URLs. Users with a query, path or credential in the address must supply a clean loopback root. Denied credentials no longer cause repeated background stream requests. Explicit reconnect creates a new subscription.

Revert the K1 implementation commit to restore prior connection behavior; no source-note or derived-state migration is involved. Do not reset the branch or remove unrelated staging files. This is the first K1 slice, not completion of retrieval, managed MOC integration or the complete build plan.
